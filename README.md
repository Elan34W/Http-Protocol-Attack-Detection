# Mendeteksi Serangan pada protokol http Menggunakan Random Forest Pada Log NGINX

Penerapan metode random forest dalam mendeteksi serangan pada protokol http

## Installation

1. Clone repository:
    ```bash
    git clone https://github.com/Elan34W/Http-Protocol-Attack-Detection.git
    ```
2. Masuk ke project directory:
    ```bash
    cd Http-Protocol-Attack-Detection
    ```
2. Buat folder baru "data" dan masukkan data di folder tersebut:
3. Install the library yang dibutuhkan (jika belum terinstall):
    ```bash
    pip install pandas
    pip install scikit-learn
    pip install matplotlib
    ```
4. Run code nya
